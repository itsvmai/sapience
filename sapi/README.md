# Sapience Coffee Website

This is a coffee shop website built with HTML, CSS, and JavaScript.

## Features

- Responsive design
- Shopping cart functionality
- User authentication (login/signup)
- Product catalog
- Contact forms
- Blog section

## Deployment on Netlify

This website is ready to deploy on Netlify:

1. Connect your GitHub repository to Netlify
2. Set the build command to empty (no build needed)
3. Set the publish directory to the root folder
4. Deploy!

## File Structure

- `index.html` - Home page
- `Products.html` - Products page
- `Cart.html` - Shopping cart
- `checkout.html` - Checkout page
- `Log-In.html` - Login page
- `Sign-Up.html` - Sign up page
- `About-Us.html` - About us page
- `Contact.html` - Contact page
- `blog/` - Blog pages
- `images/` - Image assets
- `auth.js` - Authentication logic
- `cart.js` - Shopping cart logic
- `checkout.js` - Checkout logic

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage for cart and authentication
- Responsive design
